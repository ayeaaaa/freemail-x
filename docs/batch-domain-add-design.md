# 批量添加域名设计

## 目标

在主邮箱系统 `18080` 的“新增根域名”输入框中支持一次输入多个域名，用英文逗号 `,` 分割。

示例：

```text
a.com,b.com,c.com
```

点击“添加”后，系统应把三个域名都加入 Freemail 域名列表。

## 范围

本次只增强主页面已有的“添加域名”功能。

不修改独立域名迁移工具 `18100`，不修改 `/api/create`，不修改邮件收发逻辑。

## 推荐实现

保持后端 `POST /api/domains` 单域名接口不变。

前端在点击“添加”时：

1. 读取输入框内容。
2. 按英文逗号 `,` 分割。
3. 对每个域名执行 `trim().toLowerCase()`。
4. 过滤空值。
5. 去重。
6. 逐个调用现有 `POST /api/domains`。
7. 重新加载域名列表。
8. 用 toast 显示结果。

## 行为

单个域名仍然可用：

```text
a.com
```

批量域名可用：

```text
a.com,b.com,c.com
```

输入中有空格也应该兼容：

```text
a.com, b.com, c.com
```

重复域名只提交一次：

```text
a.com,a.com,b.com
```

## 错误处理

如果全部成功，显示：

```text
已添加 3 个域名
```

如果部分失败，显示：

```text
已添加 2 个域名，失败 1 个
```

如果没有有效域名，显示：

```text
请输入域名
```

## 不改后端的原因

现有后端 `POST /api/domains` 已经支持单个域名添加，并且数据库层有去重逻辑：

```sql
ON CONFLICT (domain) DO NOTHING
```

前端循环调用现有接口可以减少风险，避免影响迁移工具和其他调用方。

## 验证

实现后需要验证：

1. 输入单个域名可以添加。
2. 输入 `a.com,b.com,c.com` 可以批量添加。
3. 输入带空格的列表可以添加。
4. 输入重复域名不会报错。
5. 添加后域名下拉框刷新。
